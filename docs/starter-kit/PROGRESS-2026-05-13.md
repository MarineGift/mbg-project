## 🚦 알려진 제약 / 짚어둘 점

### IMAP — Outlook 동시 접속 시 IDLE 충돌
- 이전에 `ceo@` inbox로 polling 시 Outlook이 동시 사용해서 자동 read 처리 → 워커가 unread 메일 못 잡음
- 해결: `contact@`를 mailcarrier 전용으로 분리. Outlook은 ceo@만 사용.
- Phase 2에서 3 box polling 시 같은 이슈 고려 필요.

### SMTP — 외부 도메인 발송 시 SPF 검증
- 이전 marine-gift.com 도메인의 ceo@ 자격증명으로 marinegift4u@gmail.com 주소를 From으로 발송 시도 → UPM Microsoft Exchange가 SPF 실패로 거부 (550 5.4.1)
- 교훈: From header는 SMTP 인증 username과 같은 도메인이어야 함
- Phase 1 코드는 kind 자격증명의 username을 From으로 강제 → 자동 일관성 보장

### OpenAI quota 소진 (RAG embedding)
- prompt-renderer가 OpenAI text-embedding-3-large 호출 시 429 quota exceeded
- RAG 없이 fallback으로 계속 진행 (정확도 약간 손실, 처리 자체는 진행)
- 운영 가시면 billing 추가 또는 모델 변경

### 인코딩 (CJK)
- `drafts.ts` 원본의 한글 주석이 일부 깨져 있던 것 발견 — 새 버전에서 모두 정상 한글로 복원

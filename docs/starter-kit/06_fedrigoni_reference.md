## 14. 위험 / 주의 항목

1. **Bain Capital ownership**: 2018-04 인수 후 still private. IPO 계획 가능성 모니터링.
2. **Fabriano 1264년 papermaking 역사**: 세계에서 가장 오래된 paper-making 도시 중 하나. notes에 역사적 의의 표기 가능.
3. **Mohawk 2024-02 인수**: distressed sale, NewCo 구조 — 일부 부채 청산되지 않은 채 인수. 원래 Mohawk은 가족 소유 (1931 설립). DB에 Mohawk Fine Papers Inc.가 별도로 남아있으면 통합.
4. **Arjowiggins China**: 모기업 Arjowiggins SAS (France)가 2019년 도산 → Arjowiggins China는 2024년 Fedrigoni가 인수. Arjowiggins 자체는 Fedrigoni와 무관.
5. **Ritrama North America (예외)**: 2020년 Ritrama 인수 시 **북미 사업은 Rink family가 유지** — 즉 Ritrama North America는 Fedrigoni family와 분리. DB 매핑 시 주의.
6. **Manter, Arconvert, Ritrama**: 세 브랜드 모두 Fedrigoni Self-Adhesives 산하지만 각자 독립 브랜드 유지. DB에 별도 row면 OK.
7. **Tageos (RFID)**: 자회사로 통합되어 있으나 RFID/NFC label tags 전문 — paper mill이 아님. paper_mills 테이블에 있으면 잘못된 분류.
8. **GPA**: 미국 distributor (paper distributor) — mill이 아닐 가능성. DB 확인.

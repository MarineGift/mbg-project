## PowerShell traps (do not repeat)

1. TSX generics break here-strings — use Base64 WriteAllBytes for all .tsx files
2. `[module]` directory = wildcard — use `-LiteralPath` for Get-Content
3. Korean in scripts corrupts on paste — ASCII-only source
4. Backtick in PS1 here-strings breaks template literals — use string concat instead
5. `-Raw` flag unavailable in older PS — use default Get-Content
6. `powershell -ExecutionPolicy Bypass -File` required for unsigned scripts

## PowerShell traps learned today

1. **esbuild "Unexpected }" errors that move line numbers** = file is structurally
   broken from mojibake fragments creating phantom syntax. Don't chase the line number
   — restore from last-known-good git tag and strip non-ASCII bytes.
2. **`[System.IO.File]::ReadAllBytes` + filter < 0x80** is the safest non-ASCII strip
   (no encoding interpretation, won't corrupt multi-byte UTF-8 fragments further).
3. **Here-strings with `.Contains()` for replace** is fragile: leading whitespace,
   CRLF vs LF, and any character drift fails the match silently. Prefer:
   - Line-by-line `-match` regex for targeted edits
   - `git checkout <tag> -- <file>` for wholesale restore
4. **`-Raw` parameter** unavailable in older PowerShell — use `[System.IO.File]::ReadAllText`.
5. **`[id]` directory in paths** = wildcard for `Get-Content`. Always use `-LiteralPath`.
6. **`patch-*.ps1` working files** are now in `.gitignore` (added today).

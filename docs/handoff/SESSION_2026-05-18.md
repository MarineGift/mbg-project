## PowerShell 교훈 (누적)
- `utf8NoBOM` → PowerShell 5.x 미지원, `utf8` 사용
- `head` 명령 없음 → `Select-Object -First N`
- `[id]` 디렉토리 → `-LiteralPath` 필수
- here-string `.Contains()` fragile → 라인별 `-match` regex 사용
- esbuild "Unexpected }" → 파일 구조 깨짐, git tag에서 복원 + 바이트 strip
- `[System.IO.File]::ReadAllBytes` + `$_ -lt 0x80` 필터 = 가장 안전한 ASCII strip

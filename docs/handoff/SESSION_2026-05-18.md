## PowerShell traps learned (do not repeat)

1. TSX generics break here-strings (`React.forwardRef<T>` becomes broken) -> use Base64 encoding for full files
2. `[module]` directory name = wildcard in PowerShell -> use `-LiteralPath` or `[System.IO.File]`
3. Korean in scripts corrupts on paste -> keep source ASCII-only, Korean only in i18n JSON
4. `package.json` raw text replace is dangerous -> use `ConvertFrom-Json` + `ConvertTo-Json` instead
5. Mojibake in `.tsx` breaks JSX silently - build passes but rendering breaks -> ASCII-only source

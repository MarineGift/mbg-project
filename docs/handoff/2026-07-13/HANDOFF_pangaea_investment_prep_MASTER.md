## 1. 확정된 실제 사실 (IR Ver3.3 + CEO 설명 — DD에서 검증됨, 과장 금지)

**트랙션 — 9,000톤의 정직한 성격**
- 로컬 충전제 제조사와 FCC 생산 → 한국 탑 제지사 공급, **양산공정 테스트 완료**.
- 작년 12월 **9,000톤 실제 발주** → 협력 충전제사 **MOQ(최소 3만 톤)** 이슈로 **일시 중지**.
- 현재: 글로벌 탑 충전제 제조사 **인접 제지사**에서 재개 협의. **4자 NDA 진행 중**(오더 제지사 + PCC 제지사 + 글로벌 탑 충전제사 + 마린바이오).
- PCC 제지사도 FCC 희망(bulk 품질·원가) → 복사지·CWF·난연벽지 원지 확장 희망.
- ★ 프레이밍: "확정 계약"이 아니라 "발주+양산테스트 완료 + MOQ로 공급처 재조정 + 4자 NDA". **멈춘 이유가 기술이 아니라 제조 물량**이 핵심.

**티슈 validation — 제3자 검증**
- 한국 티슈 제조사가 **직접 생산해 품질검증 완료** (마린바이오 데이터 아님 = 더 강력).
- 데이터가 우리 것이 아니어서 **미국 TPIL에서 샘플 생산 → 미국·글로벌 제조사 직접 공급 예정**. 특별한 관심 받음. NDA 시 전체 공개.

**IP — 방패가 아니라 무기**
- 5 granted(KIPO, 2013–2025) + 7 pending(KR·PCT·US).
- **Kleannara(한국 대형 티슈사)가 'FCC for tissue' 출원 → KIPO가 2026-04-10 거절** (CTO의 2020 ACS 논문을 prior art로 인용). USPTO·EPO third-party submission으로 해외 차단.
- SEM 포렌식으로 공장 접근 없이 침해 탐지(24–48h).
- CTO(Seo 교수) ACS 논문 2편(Han 2020, Kim 2022)이 core mechanism peer-review 근거.

**팀**
- Heo(CEO): 공학 학사, 삼성그룹 출신, 총괄.
- Seo(CTO): SUNY 박사·포닥, 충남대 교수, 해양 나노섬유 특허 50+, ACS 논문 저자.

## 3. 핵심 전략 (미팅 내내)
1. **Traction-first**: 원리 설명 전, 3분 안에 "생산 오더 + 3개국 특허 + 탑 제조사 로열티 협상 + $5M 자기자본"을 던진다.
2. **자본 효율성 + conviction**: "$5M 자기자본, 외부 투자 0, 첫 기관투자" → Pangaea의 "lean, capital-efficient" 선호에 정확히 꽂힘.
3. **Seed/Bridge 통합**: "명칭은 Seed, 구조는 bridge-to-royalty, 트랙션은 Series A급". 어느 쪽으로 물어도 같은 답.
4. **CarbonCure 정밀**: 그의 딜. 같은점3(둘 다 CaCO3 / CAPEX 최소 / 경제성이 채택) / 다른점1(FCC는 하드웨어·CO2 공급망 불필요). 피상적 비유 금지.
5. **impact 숫자 지참**: 확정 물량 연 3,700–4,600 t CO2 + 27만 m³ 물(보수적 하한). 스케일 시 10만t→5만t CO2. Pangaea 2030 목표 연결.
6. **정직이 무기**: 9,000톤=발주/MOQ, 티슈=제3자, Year-3/$5M=추정. 엔지니어는 과장을 즉시 잡는다.
7. **영어/서면 follow-up**: 미팅 초반에 "복잡한 질문은 서면으로 정확히" 미리 깔기. 약점을 강점으로.

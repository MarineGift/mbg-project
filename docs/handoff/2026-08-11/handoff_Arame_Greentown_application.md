# Arame Materials — Greentown Labs 지원 검토 핸드오프

**작성일:** 2026-08-10 · **작성 배경:** Marinebio Group의 C2V Year 6 지원서 제출 완료 후, 별건으로 착수

이 문서는 새 대화에서 단독으로 읽어도 되도록 작성했습니다. 이전 대화 맥락 없이 그대로 사용 가능합니다.

## 1. 왜 이 검토를 하는가

Marinebio Group은 C2V Year 6에 지원을 마쳤습니다(2026-08, 마감 8/28). 그 과정에서 **Arame Materials를 C2V에 별도 지원시킬지**를 검토했고, 결론은 **올해는 지원하지 않는다**였습니다. 이유:

- Arame의 자격 근거는 성립함 — 해조 추출물 제조 후 남는 **적조류 잔사(industrial residue / waste biomass)**를 DSCNF로 밸로리제이션. C2V RFA 스코프의 "Carbon-rich waste to value"에 해당
- 그러나 C2V 심사는 tCO₂eq·LCA·MRV 중심인데 **Arame은 탄소 회계가 전무**했고, 마감까지 18일로 Section 3(4문항)을 채울 시간이 없었음
- 두 회사가 **기술 개발자(CTO)를 공유**하므로, 동시 지원 시 판정단에게 "한 팀이 두 장"으로 읽힐 위험

따라서 **Arame은 C2V가 아닌 Greentown Labs 쪽 경로를 먼저 본다**는 것이 이번 검토의 출발점입니다.

### 기술

**DSCNF** (홍조류 유래 판상형 셀룰로스 나노섬유)를 식품 포장용 **생분해성 배리어 코팅**으로 사용.

- 원료: 해조 추출물(카라기난 등) 제조 후 잔사 — 연 1,000만 톤 이상 양식되는 홍조류
- **분쇄 공정 불필요** — DSCNF가 자연 상태에서 이미 200nm 두께 / 20µm 길이. 목재 CNF는 나노화에 17 MWh/t 소요되어 상용화 실패
- **판상 구조** → 8~10% 농축 가능 → 1~2회 코팅으로 고배리어 달성 (선형 CNF는 2% 한계, 반복 코팅 필요)
- 제품: **Plaban** (연포장용 배리어 코팅), **Edicoat** (과채류 신선도 코팅)

## 5. 새 대화에서 확인해야 할 것

### A. 자격·경로 (최우선)

1. **Greentown Labs는 미국 법인이 없는 외국 기업을 받는가?** Arame은 한국 법인이며 미국 자회사가 없음
2. **멤버십 종류** — 데스크/랩 벤치/버추얼/소프트랜딩 프로그램 등 어떤 티어가 있는가
3. **랩 벤치가 필요한가** — Arame은 코팅 시험이 필요하므로 데스크만으로 부족할 수 있음
4. **국제 스타트업 대상 프로그램**(soft-landing, Greentown Go 등) 존재 여부와 지원 시기
5. **비자·법인 요건** — 멤버십에 미국 법인 설립이 전제되는가

### B. 전략

6. **Somerville vs Houston** — Arame의 고객은 포장·소비재(Amcor, Unilever, Nestlé). 휴스턴은 에너지·소재 중심. 보스턴 쪽이 나을 수 있음
7. **Marinebio와 같은 캠퍼스에 들어가는 것이 유리한가, 불리한가**
8. **Marinebio의 8/20 투어에서 Arame 건을 같이 물어볼 것인가** — 가장 저렴한 정보 획득 경로

### C. 준비물

9. Arame용 영문 소개자료는 이미 존재 (22페이지). Greentown 지원서 양식에 맞춰 축약 필요 여부
10. Arame의 **탄소 감축 근거** — C2V 검토 시 산출한 추정: 코팅 1톤이 3.5~5톤의 복합 플라스틱 필름을 대체 → **약 9~15 tCO₂e/톤 회피**. 단, 실제 도포량(g/m²) 미확인 상태의 추정치이므로 사용 전 검증 필요

## 6. 참고 — C2V 검토 때 산출한 Arame 탄소 계산틀

| 항목 | 값 | 비고 |
|---|---|---|

| 코팅 1톤 커버 면적 | ~71,000 m² | |
| 대체 라미네이트 | 50~70 g/m² | PET/AL/LDPE 복합 |
| 대체 플라스틱 질량 | 3.5~5 톤 | |

**두 번째 효과:** 복합 플라스틱은 재활용 불가 → 섬유·수지 영구 손실. 모노머티리얼 종이 포장은 재생지 회수 경로 진입. 시스템 레벨 회피이며 Veolia·L'Oréal류가 관심 갖는 지점.
